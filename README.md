# 视觉分拣数字孪生系统

用 iPhone 拍一张照片：照片里是一张贴了 4 个 ArUco 码的 A4 底板，板上放着电阻和各色 LED。网页识别出零件，在 3D 里按真实尺寸重建桌面和零件，再由虚拟机械臂按类别（LED 按颜色）分拣进料盒。纯前端静态网页，不需要后端。

在线体验：<https://shixin08052.github.io/yolohtml/>（打印标定板：`board.html`；加 `?demo` 进入演示模式）

## 流程

1. **识别**：读取照片 → 识别 ArUco 码、求单应性 → 反推拍照时手机的位姿 → YOLO26n 检测零件（浏览器里 WebGPU / WASM 推理），颜色分割补漏，按 LED 的固定尺寸修正挤在一起时偏大的框
2. **定位**：检测框映射到底板毫米坐标（含视差修正）；看引脚定零件朝向，判断 LED 颜色
3. **执行**："照片 → 3D"转场；机械臂逆运动学规划，挤在一起的零件先拨开再夹，避开引脚；导出分拣指令（CSV / JSON）

## 使用

- 打开页面，选示例照片或上传自己拍的照片（底板用 `board.html` 按 100% 打印）
- 普通模式：右侧信息面板显示每一步的参数、误差和耗时，可手动框选、导出流程图 / 零件图片 / 分拣指令
- 演示模式（顶栏按钮或地址加 `?demo`）：只显示流程图，识别后先给出正视图请确认，确认后再建模分拣

## 开发

```bash
npm install
npm run dev     # 本地开发
npm test        # 单元测试（vitest）
npm run build   # 构建到 dist/
```

推送到 `main` 后由 GitHub Actions 测试、构建并部署到 GitHub Pages（`.github/workflows/pages.yml`）。

## 目录

- `src/vision/`：内参、ArUco、单应性、位姿、检测、坐标映射、引脚与颜色
- `src/robot/`：逆运动学、分拣规划、拨开、动作序列、指令导出（纯函数，有单元测试）
- `src/scene/`、`src/ui/`：Three.js 场景与界面
- `training/`：YOLO 训练（Colab）与报告；`tools/`：相机标定
- `docs/TASKS.md`：开发任务书与完整变更记录
